# 离线微信葵花码：实测结果

## 当前结论

已经实现不调用官方生成接口的本地 WX_CODE 生成命令，能够导出 PNG/SVG，并通过本地原生解码器逐码回读核对网址。实现位于 `native-probe/`，详见其 `README.md`。

**尚未完成当前手机微信的实扫与跳转验收。** 原生库识别成功不是当前微信客户端路由的替代证明，也不保证微信放行所有目标网站。

## 重要纠正

初期仅根据小程序图标推测“码内是小程序短 ID、扫码后再查表跳网页”，并不适用于所有葵花码，且当时没有解码证据。

本轮在无网络命名空间内，使用 QBar 原生解码器读取用户提供的样图，实际结果为：

```text
QBAR_VERSION=3.2.20190712
GET_RESULT_RETURN=1
DECODED_TYPE=WX_CODE
DECODED_CHARSET=ISO8859-1
PAYLOAD_BASE64=aHR0cHM6Ly9saW51eC5kby8=
PAYLOAD_UTF8=https://linux.do/
```

因此这张码直接携带的是 URL，不是已证实必须到微信服务器查询的小程序 ticket。没有证据证明其图形编码需要官方在线签发、数字签名或 AppSecret。

小程序官方 API 的 scene 长度与 web-view 域名条件，是官方小程序业务流程的限制，不能直接作为“原生 WX_CODE 不能离线编码 URL”的依据。

## 原图核查

- 文件：`pasted/pasted-ac8b9193-5374-492f-9709-8af0190e272b-image.png`。
- 500×500，8 位 RGB PNG，92,801 字节。
- SHA-256：`026cb5430444911cc704487f4b1bef859a9377ad2926008b973cf74f8d0eeb86`。
- PNG 仅含 IHDR、IDAT、IEND，无文本/EXIF/尾部额外数据；URL 来自图形码元解码，不是文件元数据。
- 像素测量得到约 36 条、间隔 10° 的径向码元线。

## 本地实现路径

原生库来源：[Haoxiqiang/wechat-re-qrscanner](https://github.com/Haoxiqiang/wechat-re-qrscanner)，固定提交 `92ca3766c614d135df0b2d20498f642a5ca35a3e`。

1. `libwechatQrMod.so` 确实包含本地 WX_CODE 编码算法；`Encode` 的 format=18 是 WX_CODE，12 是普通 QR。
2. 默认 WX 位图渲染函数在这个二进制中为空，但另有真实 SVG 渲染实现。调用程序在编码后启用原生 options 中的 SVG 标志，未改编码载荷、纠错结果或外围码元。
3. unidbg 模拟 Android ARM64，加载本地依赖与模型；补齐单核 ARM 的 CPU 文件和 getcpu 系统调用，使检测模型实际初始化成功。
4. 将 SVG 中的远程图标引用替换为内嵌本地图像，可选择中心 logo；外围数据图元保留原生输出。
5. 编码、渲染和解码子进程使用 `unshare -Urn` 在无网络命名空间内执行。没有调用微信生成或令牌接口。
6. PNG 经过本地原生解码且载荷逐字节匹配后才保存；SVG 输出也先用同样渲染结果验证。

当前版本有固定哈希与版本偏移依赖，不是独立重写的公开协议编码器。二进制分发和商用授权需另行确认，不应将第三方公开仓库里的专有库误称为完整开源协议。

## 已完成的实测

- 断网生成全新数字载荷 `12345`，原生解码得到 `WX_CODE` / `12345`。
- 断网生成全新 `https://linux.do/`，包括中心 logo，原生解码得到相同 URL。
- 使用命令行封装生成 `https://example.com/`，逐码原生回读校验通过。
- 单元测试覆盖 URL 验证/规范化、原生输出解析、SVG 保持数据图元和移除外链。

完整测试已实际执行：17/17 通过；Maven 使用 `-o` 离线构建成功。原生参数 `0/1/2` 分别固定版本，`3` 才启用原生自动选择；已据此修复较长查询链接失败的问题。百分号展开后的中文长链接仍可能超容量，测试明确覆盖失败且不留下文件，短中文链接也有实际成功用例。一次代码检查发现的域名规范化、空分隔符保留和日志解析问题均已修复，并加入实际通过的回归测试。
原生集成覆盖：原图解码、中心图片、查询/片段、中文 URL、现代 IDNA 域名、超容量不保存、拒绝误覆盖。

测试命令与依赖准备方式见 `native-probe/README.md`；测试实际结果以执行日志为准，不将测试代码的存在等同于通过。

## 仍存在的边界

- 当前环境未完成手机微信扫一扫实测，不能宣称当前微信一定接受或打开所有新码。
- 码容量有限；“任意网址”指可输入其他目标的合法 HTTP/HTTPS URL，而非无限长度。容量不足明确失败，不截断或依赖在线短链接。
- 微信客户端可能对目标网站执行安全拦截，这不由图形编码器控制。
- 当前运行环境为 Linux x86_64 + Android ARM64 模拟，未验证其他操作系统。
